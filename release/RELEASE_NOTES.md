SOL.01 0.1.0 manual edition for **Apple Silicon / Apple M4**.

Download **SOL.01-macOS-Apple-M4-0.1.0.dmg** below. Requires **macOS 15.7 or later**. Open the disk image and drag SOL.01.app to Applications. Python and libraries are already included.

The original manual interface and replay features are preserved. Native Mac automated tests, architecture checks, bundle signature checks, disk-image verification and SHA-256 verification passed.

This personal build is not Apple-notarized. If macOS blocks the first open, follow [Apple's instructions](https://support.apple.com/en-us/102445) using Privacy & Security > Open Anyway. Interactive first launch has not been tested.

Settings and trades use ~/Library/Application Support/SOL.01/data/manual/. The included synthetic demo is copied under ~/Library/Application Support/SOL.01/demo/.

The matching .sha256 file is optional verification data. The DMG is the installer.
